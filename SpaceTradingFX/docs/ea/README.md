# Unsupported MT5 reference only

`SampleEA.mq5` is retained as historical/reference source. It is disconnected
from the supported Flask paper-trading application, cannot authenticate to its
session-protected activation API, and must not be treated as a deployable EA.
It defaults to observe-only and is not included in product execution paths.

SpaceTradingFX currently supports local paper simulation only. Do not compile,
attach, or enable this reference EA for real or demo account execution.
